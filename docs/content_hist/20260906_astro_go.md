### AI

Astro AI 공식 가격 페이지 기준으로 Pay as you go는 무료 월간 크레딧으로 시작하고 추가 사용량에 대해 과금한다. Enterprise는 맞춤형 요금이다. 기준 단위는 credit이며 1 credit은 $0.001이다.

요청 비용은 에이전트 실행 컴퓨팅 비용과 AI 모델의 입력·출력 토큰 비용을 합산한다. 공식 예시는 AI 없음/자체 모델 2 credits, Haiku 5 credits, Sonnet 10 credits, Opus 15 credits다. 모델 토큰은 underlying model provider의 단가를 크레딧으로 환산하는 pass-through 방식이다.

Usage 화면에서는 Compute와 Models 사용액을 결제 기간 및 일별로 확인한다. Billing의 Manage limits에서는 알림 기준과 실제 지출 상한을 설정할 수 있다.

## 보이스톡 커맨드 기능 요청

### 사용자

특정 별칭을 시리처럼 말하면 ChatGPT/Codex 데스크톱이 웨이크업되고, 마이크 버튼이 눌리며, “오버”라고 말하면 음성 입력이 전송되는 기능을 만든다. 이 기능의 명세를 tools/보이스톡 코맨드.md에 작성하고 VS Code/Codex에 설치 가능한 플러그인 또는 companion 구성까지 포함한다.

### AI

고정 좌표 클릭이 아니라 Windows UI Automation으로 대상 창과 Voice/전송 버튼을 다시 탐색하는 구조로 명세했다. 공식 내부 Voice API를 직접 호출하는 플러그인으로 단정하지 않고, 로컬 음성 감지 companion과 VS Code/Codex 제어 플러그인을 분리하는 범위로 정의했다.

### 오해 정정

작업 완료 알림과 자동 TTS는 새로 만들 companion의 기능을 요구한 것이 아니라, 현재 Codex 데스크톱 앱 자체에서 설정 가능한지 묻는 내용이었다. 따라서 해당 내용을 플러그인 기능 명세에서 제거했다.

## 보이스 커맨드 companion 구현 기록

보이스 커맨드 명세를 기준으로 tools/plugins/voice-command-companion 플러그인을 만들고 Codex personal marketplace에 등록했다. Windows PowerShell companion은 한국어 웨이크워드와 오버, 스톱, 그만 명령을 처리하고, ChatGPT/Codex 창의 접근성 버튼을 UI Automation으로 탐색해 InvokePattern을 실행한다.

플러그인 매니페스트 검증과 PowerShell 진단은 통과했다. 현재 컴퓨터에서는 한국어 음성 인식 엔진이 설치되어 있지 않았고, 진단 시 ChatGPT 창의 Voice 버튼이 접근성 트리에 노출되지 않아 실제 음성 자동화는 추가 환경 설정과 UI 진단이 필요하다.
