# AI 뉴스와 서비스 아이디어 공유

## 목적

AI 관련 최신 소식과 실제 활용 아이디어를 정리해 사람들과 공유한다. 이 문서는 AI 모델을 활용해 수익을 만들 수 있는 서비스 아이디어를 검토할 때 참고할 수 있는 기록이다.

## Astra와 Luna Medium 비교

“최고 수준 추론·코딩·복합 작업”은 단순히 코드를 더 많이 작성한다는 뜻이 아니다. 요구사항이 모호한 상황에서 목표를 정리하고, 여러 기능과 데이터 흐름을 포함한 구조를 설계하며, 긴 작업의 맥락을 유지하고, 복잡한 버그·보안·성능·배포 문제까지 함께 다루는 능력을 의미한다.

| 항목 | Astra | Luna Medium |
|---|---:|---:|
| 용도 | 최고 수준 추론·코딩·복합 작업 | 저비용·대량 처리 |
| Reasoning effort | low~max | medium |
| 입력 가격 / 1M 토큰 | $10 | $0.20 |
| 캐시 입력 / 1M 토큰 | $1 | $0.02 |
| 출력 가격 / 1M 토큰 | $50 | $1.20 |
| 컨텍스트 창 | 1.05M 토큰 | 1.05M 토큰 |
| 최대 출력 | 128K 토큰 | 128K 토큰 |

동일한 토큰 수를 사용하면 Astra의 입력 비용은 Luna의 약 50배, 출력 비용은 약 41.7배다. 다만 Astra가 항상 더 많은 토큰을 사용하는 것은 아니며, 실제 사용량은 작업 난이도와 reasoning 설정에 따라 달라진다.

## 월 100달러 서비스에 적용할 때

월 100달러의 매출을 목표로 한다고 해서 Astra가 자동으로 더 좋은 사업 성과를 보장하지는 않는다. 매출은 모델보다 고객 수요, 문제의 명확성, 가격, 홍보와 운영에 더 크게 좌우된다.

- 아이디어 검토, 간단한 웹앱, CRUD 기능, 빠른 프로토타입: Luna Medium
- 결제·인증·외부 API·배포가 얽힌 서비스: Astra
- 기존 코드가 복잡하거나 원인 분석이 어려운 버그: Astra
- 여러 아이디어를 저비용으로 실험하고 반복 수정: Luna Medium

현실적인 방법은 Luna Medium으로 MVP를 만들고, 서비스 구조 설계·결제·인증·보안·복잡한 오류 해결·출시 전 점검처럼 판단 난도가 높은 단계에서 Astra를 사용하는 것이다.

Astra는 더 잘 팔리는 아이디어를 자동으로 만들어주는 모델이라기보다, 복잡한 아이디어를 실제 작동하는 서비스로 완성할 가능성을 높여주는 도구에 가깝다.

## Git을 통한 공유

AI 뉴스와 사용 아이디어, 모델 비교와 서비스 제작 경험은 이 저장소의 `docs` 폴더에 Markdown으로 계속 기록한다. 정리된 문서는 Git을 통해 버전 관리하고, 커밋과 원격 저장소 공유를 통해 다른 사람들과 공개적으로 나눈다.

새로운 AI 뉴스나 활용 아이디어를 발견하면 다음 내용을 중심으로 기록한다.

1. 무엇이 새롭거나 유용한가
2. 어떤 사람이나 문제에 적용할 수 있는가
3. 어떤 모델과 도구가 적합한가
4. 예상 비용과 한계는 무엇인가
5. 실제 서비스로 검증할 수 있는 가장 작은 실험은 무엇인가
