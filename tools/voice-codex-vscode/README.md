# Voice Codex for VS Code

VS Code에서 한국어 음성으로 코딩 어시스턴트에 프롬프트를 보내는 companion 확장입니다.

## 음성 명령

- 올려, 보내, 전송: 현재 문장을 Codex/VS Code Chat으로 전송
- 스톱, 중지, 멈춰: 듣기 중지
- 그만, 종료: 듣기 종료 및 문장 초기화

## 사용

1. 확장을 설치합니다.
2. Activity Bar의 Voice Codex 아이콘을 엽니다.
3. 듣기 시작을 누르고 한국어로 말합니다.
4. 올려라고 말하면 Codex/VS Code Chat 전송을 시도합니다.

공식 Codex 확장 내부에 삽입하는 방식이 아니라 VS Code의 공개 Chat 명령을 사용합니다.
Chat 명령을 사용할 수 없으면 문장을 클립보드에 복사합니다.
