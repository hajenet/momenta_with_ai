# Momenta with AI

AI와 함께 만들 수 있는 서비스 아이디어와 검증 경험을 기록하고 공유하는 저장소입니다.

## 목적

AI 관련 최신 소식과 실제 활용 아이디어를 정리하고, AI 모델을 활용해 수익을 만들 수 있는 서비스 아이디어를 검토하기 위한 참고 기록으로 사용합니다.

아이디어를 단순히 모으는 데 그치지 않고, 어떤 사람의 어떤 문제를 해결하는지와 실제 서비스로 검증할 수 있는지를 함께 살펴봅니다.

## 기록 원칙

새로운 AI 뉴스나 서비스 아이디어를 발견하면 다음 내용을 중심으로 기록합니다.

1. 무엇이 새롭거나 유용한가
2. 어떤 사람이나 문제에 적용할 수 있는가
3. 어떤 모델과 도구가 적합한가
4. 예상 비용과 한계는 무엇인가
5. 어떤 방식으로 실제 서비스 검증을 시작할 수 있는가

## 사용 흐름

Codex에서 대화를 시작하고, `contents/YYYY/MM/topic/` 아래의 콘텐츠와 관련된 이름의 Markdown 파일에 내용을 계속 추가합니다. 필요한 이미지·YouTube 링크와 글 하단의 출처 URL을 확인한 뒤 Blogger 비공개 초안으로 등록하고, 화면 검수 후 공개합니다. 자세한 순서는 [작성 프로세스](process.md)를 참고합니다.

## 모델 활용 방향

서비스 아이디어를 빠르게 실험하고 반복 수정할 때는 비용 효율적인 모델을 우선 검토합니다. 결제, 인증, 외부 API, 배포, 보안처럼 복잡도와 위험이 높은 작업이나 기존 코드의 어려운 분석에는 더 높은 추론 성능을 가진 모델을 검토합니다.

모델이 서비스의 성공을 자동으로 보장하는 것은 아니므로, 고객의 필요와 문제의 명확성, 가격, 운영 방식 및 실제 검증 결과를 함께 판단합니다.

## 기여 및 공유

문서는 Markdown으로 작성하며 Git으로 변경 이력을 관리합니다. 새로운 기록을 추가할 때는 위 기록 원칙을 참고하고, 다른 사람이 아이디어의 배경과 검증 가능성을 이해할 수 있도록 작성합니다.
